🤝 Thread2MQTT v0.5 — Open-Source MIT & Contribuer

      
    

    

      
Thread2MQTT est un projet open-source MIT, léger et ouvert à tous, écrit en Rust pur std (0 crate externe, < 1 Mo RAM, 0 CDN).

      

        Ambition : rendre les réseaux Thread (OTBR) et Matter-over-Thread simples à observer, diagnostiquer et exploiter au quotidien, pour accélérer l'adoption de Thread par toute la communauté domotique. Toutes les contributions sont les bienvenues !
      

      

        
• Contribuer facilement : lisez AGENTS.md et CONTRIBUTING.md pour ajouter un cluster Matter ou un appareil en quelques lignes.

        
• Photos d'appareils : déposez vos PNG 512×512 dans <data_dir>/device_images/ ou configurez frontend.device_images_base_url.

        
• Supervision native : pack prêt à importer dans monitoring/ (Grafana + alertes Prometheus + /api/alerts).

      

      

        ⭐ GitHub Open-Source
